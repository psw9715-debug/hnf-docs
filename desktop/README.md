# 혀니네홈패션 거래문서 — PC 앱

모바일 웹앱과 완전히 같은 화면/코드를 씁니다 (`../index.html`, `../app.js`를 그대로 불러와서 씀 — 코드가 두 벌로 나뉘지 않아요). 다른 점은 두 가지뿐입니다:

1. 창을 화면 전체가 아니라 화면 폭의 약 1/3, 세로로 긴 크기로 띄워서 실제 거래명세표/납품확인서 느낌이 나게 합니다.
2. 구글 로그인 방식이 다릅니다. 모바일 웹앱은 브라우저 보안 정책 때문에 로그인이 자주 풀리는데, PC 앱은 **최초 1회만 로그인하면 그 다음부터는 영원히(!) 다시 로그인 화면이 뜨지 않습니다.** 아래 "왜 PC에서는 재로그인이 없는지" 참고.

## 설치 (컴퓨터에 처음 받을 때 한 번만)

1. [Node.js](https://nodejs.org) 설치 (LTS 버전이면 충분합니다)
2. `D:\` 드라이브에 이 저장소를 받습니다. PowerShell에서:
   ```powershell
   cd D:\
   git clone https://github.com/psw9715-debug/hnf-docs.git
   cd hnf-docs\desktop
   npm install
   ```
   (이미 로컬 Claude Code CLI가 D:\에 설정되어 있으니, 그걸로 `git pull`만 해도 됩니다.)
3. 실행:
   ```powershell
   npm start
   ```

이후 업데이트는 `D:\hnf-docs` 폴더에서 `git pull` 한 번이면 됩니다 (웹앱 코드와 100% 공유하기 때문에, 모바일에서 반영된 서식/기능 개선이 PC 앱에도 그대로 적용돼요).

## 최초 설정 (앱 안에서, ⚙️ 설정 화면)

### 1. 공급자 정보 / GitHub 토큰 / 구글 클라이언트 ID (웹앱용)
모바일 웹앱과 완전히 같은 항목입니다. 이미 모바일에서 GitHub 동기화를 연결해두셨다면, 여기서도 같은 GitHub 토큰을 넣으면 주소록·거래이력·발송이력이 그대로 동기화됩니다.

### 2. "🖥️ PC 앱 전용 설정" 카드 — 데스크톱용 구글 클라이언트 발급 (최초 1회, 계정 소유자만)

PC 앱은 **"데스크톱 앱" 유형**의 별도 구글 OAuth 클라이언트가 필요합니다 (모바일 웹앱이 쓰는 "웹 애플리케이션" 유형과는 다릅니다). 이미 만들어둔 구글 클라우드 프로젝트(hnf-docs)에 하나 추가하면 됩니다:

1. `suhyunfabric@gmail.com`으로 console.cloud.google.com 로그인 → 기존 hnf-docs 프로젝트 선택
2. "API 및 서비스" → "사용자 인증 정보" → "+사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"
3. **애플리케이션 유형: "데스크톱 앱"** 선택 (중요! 웹 애플리케이션 아님)
4. 이름은 아무거나 (예: hnf-docs-desktop) → 만들기
5. 발급된 **클라이언트 ID**와 **클라이언트 보안 비밀번호(시크릿)** 둘 다 복사

   → PC 앱의 ⚙️ 설정 → "🖥️ PC 앱 전용 설정" 카드에 각각 붙여넣고 저장

6. **"OAuth 동의화면"을 반드시 "테스트"에서 "프로덕션(게시)"으로 전환하세요.** (아래 이유 참고 — 안 하면 로그인이 7일마다 풀립니다)
   - "API 및 서비스" → "OAuth 동의화면" → "앱 게시" 버튼 클릭
   - "확인되지 않은 앱" 관련 안내가 나오지만, 어차피 suhyunfabric@gmail.com 본인만 쓰는 개인 도구라 문제 없습니다. 검증(verification) 절차를 굳이 거칠 필요 없어요.

7. 설정 카드에서 "🔐 구글 로그인" 클릭 → 시스템 기본 브라우저가 뜨고, suhyunfabric@gmail.com으로 로그인/동의 → 완료.

**이게 이 순서로 끝이에요.** 이후 앱을 껐다 켜도, 컴퓨터를 재부팅해도 다시 로그인 화면이 뜨지 않습니다.

### 왜 PC에서는 재로그인이 없는지 (모바일과 다른 이유)

- 모바일 웹앱은 브라우저(GIS) 방식이라 진짜 "재발급 토큰(refresh_token)"을 못 받고, 매번 짧게 사는 토큰을 "조용히" 다시 받아오는 방식을 씁니다. 사파리는 개인정보 보호 정책 때문에 이 "조용한 갱신"을 자주 막아서 재로그인 화면이 뜹니다 — 이건 앱이 아니라 브라우저의 한계라 고칠 수 없어요.
- PC 앱은 진짜 설치형 프로그램이라 최초 1회 로그인할 때 **refresh_token**(재발급 토큰)을 정식으로 받아서, 이 컴퓨터에 암호화해서 저장해둡니다(윈도우 자체 암호화 기능 사용, 평문 저장 아님). 이후엔 브라우저를 전혀 열지 않고 이 refresh_token으로 서버와 직접 통신해서 새 접속 토큰을 받아옵니다 — 사람이 개입할 일이 원천적으로 없습니다.
- 단, 구글은 "OAuth 동의화면"이 "테스트" 상태인 동안은 이 refresh_token도 7일마다 강제로 끊어버립니다. 그래서 위 6번처럼 "프로덕션(게시)"으로 바꾸는 게 핵심입니다 — 한 번만 바꿔두면 그 뒤로는 무기한입니다.
- 컴퓨터 자체에 어떤 윈도우/구글 계정으로 로그인해 있는지(예: 박시우 개인 계정)는 이 앱의 구글 로그인과 완전히 무관합니다. 앱은 항상 최초에 동의한 그 계정(suhyunfabric@gmail.com, 김수현)으로만 동작합니다.

## 로컬 저장 폴더

기본적으로 `D:\hnf-docs-desktop\pdf-archive\{거래처명}\` 아래에 PDF가 그대로 쌓입니다 (PDF를 생성하는 순간 GitHub·구글드라이브 백업과 동시에 여기도 저장됩니다). 설정 화면에서 "📂 폴더 열기"로 바로 탐색기가 열립니다. 외부에서 급하게 찾아야 할 땐 모바일 웹앱(발송이력 화면)에서 GitHub/Drive 링크로 열어보면 됩니다 — 셋 다 같은 파일을 가리킵니다.
